2. PROFIL PROJECT

2.1 Identitas Proyek

Nama Aplikasi: TANI-SCAN

Kepanjangan: Tanaman Identification and Disease Scanner

Kategori: Smart Agriculture

Jenis Aplikasi: Web Application

Teknologi Utama: Artificial Intelligence dan Image Processing

Target Pengguna: Petani, mahasiswa pertanian, dan masyarakat yang bergerak di bidang budidaya tanaman.

2.2 Latar Belakang

Sektor pertanian memiliki peran penting dalam memenuhi kebutuhan pangan masyarakat. Namun, salah satu permasalahan yang sering dihadapi dalam kegiatan pertanian adalah munculnya penyakit pada tanaman.

Kurangnya pengetahuan dalam mengenali gejala penyakit tanaman dapat menyebabkan keterlambatan penanganan. Selain itu, beberapa penyakit memiliki gejala visual yang hampir serupa sehingga sulit dibedakan secara langsung.

Berdasarkan permasalahan tersebut, dikembangkan TANI-SCAN sebagai aplikasi berbasis web yang memanfaatkan teknologi Artificial Intelligence (AI) untuk membantu mengidentifikasi kemungkinan penyakit tanaman melalui analisis gambar daun.

Dengan adanya aplikasi ini, pengguna diharapkan dapat memperoleh informasi awal mengenai kondisi tanaman, gejala penyakit, serta rekomendasi penanganan yang sesuai.

2.3 Deskripsi Proyek

TANI-SCAN merupakan aplikasi berbasis web yang dirancang untuk membantu pengguna mengidentifikasi kemungkinan penyakit tanaman melalui gambar daun menggunakan teknologi Machine Learning.

Pengguna dapat mengunggah foto daun tanaman melalui aplikasi. Selanjutnya, sistem akan memproses gambar menggunakan model kecerdasan buatan untuk menghasilkan prediksi jenis penyakit berdasarkan pola visual yang terdeteksi.

Hasil analisis akan ditampilkan dalam bentuk informasi nama penyakit, tingkat keyakinan prediksi, gejala, serta rekomendasi penanganan awal.

TANI-SCAN diharapkan menjadi media informasi dan pendukung identifikasi awal penyakit tanaman yang mudah diakses melalui perangkat komputer maupun smartphone.

2.4 Tujuan Pengembangan

1. Membangun aplikasi pendeteksi penyakit tanaman berbasis web.
2. Menerapkan teknologi Artificial Intelligence untuk menganalisis gambar daun.
3. Membantu pengguna mengenali kemungkinan penyakit tanaman lebih awal.
4. Menyediakan informasi mengenai gejala dan penanganan penyakit tanaman.
5. Mengembangkan solusi digital yang mendukung pemanfaatan teknologi dalam sektor pertanian.

2.5 Permasalahan yang Diidentifikasi

1. Sulitnya mengenali penyakit tanaman berdasarkan gejala visual.
2. Terbatasnya akses informasi mengenai jenis penyakit tanaman.
3. Kurangnya pemanfaatan teknologi AI untuk membantu identifikasi awal penyakit.
4. Risiko keterlambatan penanganan akibat kesalahan mengenali gejala penyakit.

2.6 Target Pengguna

- Petani yang membutuhkan informasi awal mengenai penyakit tanaman.
- Mahasiswa yang mempelajari bidang pertanian.
- Masyarakat yang melakukan kegiatan budidaya tanaman.
- Pengguna yang membutuhkan informasi mengenai kesehatan tanaman.

2.7 Fitur Utama Aplikasi

A. Plant Disease Scanner

Fitur untuk mengunggah atau mengambil gambar daun tanaman sebagai objek analisis.

B. AI Disease Detection

Fitur untuk menganalisis gambar daun menggunakan model Machine Learning dan menghasilkan prediksi kemungkinan penyakit.

C. Disease Information

Menampilkan informasi mengenai nama penyakit, gejala, dan karakteristik penyakit tanaman.

D. Treatment Recommendation

Memberikan rekomendasi penanganan awal berdasarkan hasil identifikasi penyakit.

E. Scan History

Menyimpan riwayat hasil pemindaian agar pengguna dapat melihat kembali pemeriksaan sebelumnya.

F. Admin Dashboard

Menyediakan pengelolaan data informasi penyakit dan rekomendasi penanganan.

3. PROJECT CHARTER

3.1 Project Overview

TANI-SCAN merupakan proyek pengembangan aplikasi berbasis web yang bertujuan membantu proses identifikasi awal penyakit tanaman melalui analisis gambar daun dengan memanfaatkan teknologi Artificial Intelligence.

Proyek ini dikembangkan sebagai bentuk penerapan ilmu Informatika dalam memberikan solusi terhadap permasalahan yang ditemukan pada sektor pertanian.

3.2 Project Objectives

- Menghasilkan aplikasi identifikasi penyakit tanaman berbasis AI.
- Mempermudah pengguna memperoleh informasi awal mengenai penyakit tanaman.
- Mengintegrasikan teknologi Machine Learning dengan aplikasi web.
- Menghasilkan sistem yang mudah digunakan dan informatif.
- Melaksanakan pengembangan proyek secara terstruktur melalui tahapan Sprint.

3.3 Project Scope

In Scope (Ruang Lingkup)

1. Pengembangan aplikasi berbasis web.
2. Fitur unggah gambar daun tanaman.
3. Pengolahan gambar menggunakan model AI.
4. Prediksi kemungkinan penyakit tanaman.
5. Penyajian informasi gejala penyakit.
6. Rekomendasi penanganan awal.
7. Penyimpanan riwayat pemindaian.
8. Pengelolaan informasi melalui admin.

Out of Scope (Di Luar Ruang Lingkup)

1. Diagnosis penyakit tanaman secara profesional.
2. Pemeriksaan kondisi tanaman menggunakan sensor fisik.
3. Pengendalian penyakit tanaman secara otomatis.
4. Integrasi langsung dengan perangkat pertanian berbasis IoT.
5. Penjaminan hasil prediksi AI selalu benar pada seluruh kondisi lapangan.
